# 品牌 Talk（品牌声音圆桌）

> 单文件、零依赖的品牌营销推演工具：输入一个话题，让 84 个品牌的真实声音卡驱动 4 位品牌嘉宾 + 1 位主持人展开两轮圆桌讨论，并输出可执行的营销总结。

- **形态**：单文件 HTML（约 180KB），双击即用，无构建、无后端、无第三方依赖
- **数据**：内嵌 84 个品牌声音卡（HuggingFace `manifesta/brandvoice-marketing-briefs`，CC0），覆盖 8 大行业
- **能力**：自动圆桌 / 灵感卡 / 推荐圆桌 / 与品牌对话 / 自定义角色 / 自由选人 / 历史管理 / 附件注入 / 暗色模式

---

## ✨ 核心功能

| 模块 | 说明 |
| --- | --- |
| 自动圆桌 | 输入话题 → 按行业匹配 4 品牌 + 1 主持人，三轮 LLM 编排（陈述 → 交锋 → 总结） |
| 自由选人圆桌 | 品牌卡片「＋」多选（最多 4 位）→ 二级页面填话题 → 按你的选择组队开桌 |
| 自定义角色 | 品牌名字 + 行业 + 系统提示词，运行时作为声音卡注入，与内置品牌同通道扮演 |
| 推荐圆桌 | 6 个预置案例，一键体验 |
| 与品牌对话 | 84 品牌按 8 大行业分类，支持搜索 / 筛选 / 收藏 |
| 历史管理 | 自动保存、搜索回看、置顶 📌、文件夹 📁、删除 🗑 |
| 品牌资料附件 | 插入 .md/.txt/.csv/.json 等文件参与讨论上下文（≤5 份 / ≤200KB / 单份 ≤6000 字） |

## 🚀 快速开始

**方式一：本地打开（零配置）**
1. 下载 `brand-roundtable.html`；
2. 浏览器双击打开；
3. 未配置 API Key 时自动进入**演示模式**，全流程可体验。

**方式二：使用真实模型**
1. 点击左下角「⚙️ 设置」；
2. 填入 API Base URL / API Key / 模型名（Key 仅保存在本机浏览器 localStorage，不上传）；
3. 回到首页输入话题，点击「开始 →」。

**方式三：在线访问**
部署到任意静态托管（GitHub Pages / Vercel / Netlify / OSS）即可，纯静态文件，不含任何密钥。

## 🧠 技术架构

```
单文件 HTML
├── 数据层：BRAND_VOICES（84 品牌声音卡）内嵌在 <script>，页面零请求渲染
├── 状态层：localStorage（Key / 历史 / 自定义角色 / 收藏 / 置顶 / 文件夹 / 主题）
└── 编排层：3 次 LLM 调用，只注入本场 5 张声音卡（约 1KB），严格 JSON 输出 + 容错解析
```

- 数据与逻辑解耦：自定义角色复用内置品牌的「声音卡通道」，扩展品牌无需改代码；
- Key 不出本机：页面直连用户自配的 LLM API，无中间服务器；
- 演示兜底：未配置 Key 时用内置预录数据完整演示。

## 🔒 隐私与安全

- 项目为纯前端静态文件，**不包含任何 API Key**；
- Key 由使用者在各自浏览器中填写，仅存于本机 localStorage；
- 页面直连 LLM API，部署端不经过、不保存任何密钥。
